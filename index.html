PROJECT OVERVIEW

An autonomous surveillance system designed to detect unauthorized mobile device usage in secured zones using client-side Neural Networks.

TensorFlow.js Core

Powered by the COCO-SSD model. The entire detection process runs directly in your browser using WebGL acceleration, ensuring zero latency.

Privacy First

No video data is sent to any server. All processing happens locally on the client's device (Edge Computing), ensuring 100% data privacy.

Smart Alerts

Features an automated Voice Alert System. When a "cell phone" class is identified with >70% confidence, the system triggers an immediate audio warning.

SYSTEM DOCUMENTATION

Follow these simple steps to activate the AI Surveillance System.

User Manual

1

Grant Permissions

Click "Allow" when the browser asks for camera access. The system needs video input to detect objects.

2

Initialize System

Click the INITIALIZE button. Wait for the "Neural Network Loaded" status message.

3

Detection & Alert

Bring a mobile phone in front of the camera. If detected (>70% confidence), the audio alarm will trigger automatically.

Technical Requirements

  • Browser Support Chrome, Edge, Firefox (Latest)
  • Camera Webcam (720p Recommended)
  • Internet Required for Model Loading
  • Light Condition Well-lit Environment
  • Framework TensorFlow.js (COCO-SSD)
